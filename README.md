# 💬 MessageMe - Real-Time Chat Application

A cross-platform real-time messaging mobile application built with Flutter and Firebase, enabling seamless user communication with a clean and modern UI.

## 🚀 Key Features

- User Authentication: Secure user sign-up, login, and sign-out flows using Firebase Authentication.
- Real-Time Messaging: Instant data synchronization for chat messages powered by Cloud Firestore.
- User Interface: Responsive, minimalist, and user-friendly design.
- Message Timestamps: Clear message history and real-time feed updates.

---

## 🛠️ Tech Stack & Tools

- Framework: [Flutter](https://flutter.dev) (Dart)
- Backend Services: Firebase Authentication, Cloud Firestore
- IDE: Visual Studio Code / Android Studio

## 📱 Getting Started & APK

You can download the latest release APK from the [Releases](https://github.com/AyhamSai/portfolio/releases) section or clone the repository to run the app locally:

`bash
# Clone the repository
git clone [https://github.com/AyhamSai/chatting_app.git](https://github.com/AyhamSai/chatting_app.git)

# Install dependencies
flutter pub get

# Run the application
flutter run
